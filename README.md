# Переводчик для Galaxy Watch (Wear OS)

Офлайн-перевод на 59 языков (русский, финский, болгарский — в начале списка), ввод голосом или клавиатурой, озвучка перевода.

## Сборка APK

**Вариант 1 — Android Studio (ПК):** File → Open → папка `WatchTranslator` → Build → Build APK(s).
APK: `app/build/outputs/apk/release/app-release.apk` (или debug).

**Вариант 2 — GitHub (без ПК-программ):** создать репозиторий, загрузить все файлы проекта
(вместе со скрытой папкой `.github`). Вкладка **Actions** → сборка «Build APK» запустится сама →
по завершении внизу страницы скачать артефакт **Perevodchik-APK**.

## Установка на часы
Как обычно для своих циферблатов: включить «Отладку по Wi‑Fi» на часах и поставить APK
(adb / Bugjaeger / Wear Installer).

## Первый запуск
1. Включить Wi‑Fi на часах.
2. «Языки офлайн» → «Скачать RU + FI + BG» (≈30 МБ на язык). После этого перевод работает без интернета.
3. Если перевод не озвучивается — кнопка «Установить голос» (нужен голос для финского/болгарского
   в синтезаторе речи часов, например «Speech Services by Google» из Play Маркета на часах).

## Режим разговора
Сказали фразу → перевод сразу звучит вслух → кнопка **↩🎤** меняет языки местами
и включает микрофон для ответа собеседника.

## Телефон: лучшее качество (версия 6.0)
В приложении на телефоне → ⚙ Настройки скачайте по Wi‑Fi:
- **Быстрый микрофон** (NVIDIA Parakeet v3, ~670 МБ) — финский, русский, болгарский и ещё 22 языка.
  В тестах в 8 раз быстрее «Максимального микрофона» и точнее «Точного».
- **Умный переводчик** (Google Gemma 4 E4B, ~3,7 ГБ) — переводит напрямую FI⇄RU по смыслу,
  без английского посредника, без интернета.

Часы, если телефон рядом, сами пользуются обоими пакетами через Bluetooth.
Во время звонка: говорите по телефону на громкой связи, а переводчик запускайте на часах.

## Ограничения
- Перевод ML Kit между двумя не‑английскими языками идёт через английский — простые фразы
  переводит хорошо, сложные — приблизительно.
- Распознавание речи без интернета зависит от того, скачан ли офлайн-пакет речи на часах;
  если не распознаёт — используйте «Написать».
